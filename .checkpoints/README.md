# チェックポイント管理システム

このディレクトリは、デザイン変更履歴を管理するためのチェックポイントシステムです。

## 自動チェックポイントのルール

1. **新しい依頼の前**に、現在の状態をGitコミット
2. **コミットメッセージ形式**：`[CHECKPOINT] YYYY-MM-DD HH:MM - [変更内容の簡単な説明]`
3. **復元方法**：
   - 「このバージョンを復元して」と言うと、直前のチェックポイントに戻る
   - 「[日時]の状態に戻して」と言うと、該当のチェックポイントに戻る

## チェックポイント一覧の確認

```bash
git log --oneline --grep="CHECKPOINT" -20
```

## 特定のチェックポイントに戻す

```bash
# コミットハッシュを指定して復元
git reset --hard <commit-hash>

# または、相対的に戻す（例：1つ前）
git reset --hard HEAD~1
```
